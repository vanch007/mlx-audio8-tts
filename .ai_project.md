# MLX Audio8 TTS (ArkTTS)

- Purpose: standalone Apple Silicon MLX port of Audio8 TTS (ArkTTS) with full feature parity, conversion, serving, and evidence-driven evaluation.
- Package: `src/mlx_audio8_tts`; Python >=3.10; MLX >=0.31.0.
- Interfaces: Python `load`/`Model.generate`, `mlx-audio8-tts` CLI, FastAPI `/v1/audio/speech` and `/health`.
- Upstream reference: `Audio8-AI/Audio8_TTS` (commit `07e40f5`).
- Upstream checkpoint: `Audio8/Audio8-TTS-Preview-0.6b` (revision `1b17c91`), DualAR 24L slow + 4L fast, 44.1kHz 10-codebook neural codec.
- Approved scope: zero-shot voice cloning, multilingual generation across 11 languages (Cantonese, Chinese, English, French, German, Italian, Japanese, Korean, Polish, Spanish, Dutch), streaming & non-streaming, generation controls, CLI, HTTP serving, weight conversion and strict audit.
- Runtime constraint: zero dependency on `mlx_audio` at runtime.
- Evidence belongs in `reports/`; generated weights and audio remain untracked.
