# MLX Audio8 TTS Memory

- Production code must remain completely independent of `mlx_audio`; enforce with `tests/test_isolation.py`.
- DualAR architecture: Slow AR (24L, dim 896, vocab 155776) + Fast AR (4L, dim 896, 10 codebooks of size 4096).
- Neural codec: 44.1 kHz, frame length 2048, hop length 512, 10 codebooks (1 semantic + 9 residual quantizer codebooks).
- 8-bit quantization: uses `sensitive-bf16` policy, quantizing all 120 linear layers in Slow AR transformer while preserving depth decoder, embeddings, and codec.
- 8-bit M3 Max release benchmark: RTF 0.983 (EN), 0.922 (ZH), 0.793 (YUE), seeded after warm-up; report in `reports/evaluation/8bit-release/`.
- Languages supported: Cantonese (粤语), Chinese, English, French, German, Italian, Japanese, Korean, Polish, Spanish, Dutch.
- Public releases: GitHub `vanch007/mlx-audio8-tts`; HF `vanch007/Audio8-TTS-MLX-{8bit,BF16}`.
